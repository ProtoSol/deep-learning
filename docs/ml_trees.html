0.2 Trees and Ensembles

Created Date: 2026-10-09

A tree asks one yes-or-no question at a time. An ensemble asks many trees and votes. The code is tree_models.py. Run python 00_ml/tree_models.py. Gradient boosting is explained below and is not a second program: the runnable ensemble is AdaBoost.

0.2.1 Decision tree

Each split picks a feature and a cut that make the two sides purer. For a binary label the impurity is the Gini index. \(p\) is the fraction of ones in the node:

\(G = 2p(1-p)\)

XOR on the four corners needs both features, so a depth-1 tree misses at least one corner and a depth-2 tree fits all four. The script asserts both. Watch StatQuest: Decision Trees.

0.2.2 Bagging

Bagging draws bootstrap samples (rows sampled with replacement) and fits one tree on each. The prediction is the majority vote. A single tree copies the training set, including its accidents. Averaging trees that saw different accidents cancels some of those accidents.

The toy set is twenty-four points. The label is the sign of the first column, and the second column is noise. Twenty bootstrap trees of depth 2 vote back the true labels. StatQuest builds bagging in the first half of Random Forests Part 1.

0.2.3 Random forest

A random forest is bagging plus one extra coin flip: each split, or in this small script each tree, may look at only a subset of the columns. That keeps every tree from locking onto the same feature. Here each tree sees one of the two columns. Eighty of those trees still vote the toy labels correctly, because enough of them were allowed to see the real column. The same StatQuest video finishes the construction: Random Forests Part 1 - Building, Using and Evaluating.

0.2.4 AdaBoost

AdaBoost fits a stump, then raises the weight of the rows it got wrong, then fits the next stump on those heavier rows. A stump that is only a little better than a coin flip gets a small voice. The voices add up:

\(\alpha_t = \tfrac{1}{2}\log\dfrac{1-\epsilon_t}{\epsilon_t}, \quad H(x) = \mathrm{sign}\sum_t \alpha_t h_t(x)\)

Eight stumps on the same toy set recover the labels. Watch AdaBoost, Clearly Explained.

0.2.5 Gradient boosting

Gradient boosting fits the residual. After a tree predicts \(\hat y\), the next tree is trained on \(y - \hat y\), and its prediction is added with a small step size. Repeat. That is the whole idea. XGBoost is this loop with a smarter split score and a penalty on the leaves. The script in this section is AdaBoost. Watch Gradient Boost Part 1: Regression Main Ideas.
