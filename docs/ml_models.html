0.3 Other Models

Created Date: 2026-10-09

Four more algorithms, then the split you use to tell whether any of them worked. The code is other_models.py. Run python 00_ml/other_models.py. Two blobs of twenty points, one near the origin and one near \((3, 3)\), are far enough apart that each method on this page gets them right. PCA is the SVD section of 2.1 Linear Algebra, not a second implementation.

0.3.1 k nearest neighbors

Store the training rows. To label a new row, find the \(k\) stored rows closest to it and take their majority. There is no \(w\) to fit. With \(k = 3\) on a held-out half of the two blobs, every neighbor vote is correct. Patrick Winston's Introduction to Learning, Nearest Neighbors is the lecture for this one.

0.3.2 Gaussian naive Bayes

Naive Bayes scores a class by how common it is times how likely the features are under that class. "Naive" means the features are treated as independent, so the joint density is a product. For a Gaussian class the log score of class \(c\) is

\(\log \pi_c - \tfrac{1}{2}\sum_j \left[\log(2\pi \sigma_{cj}^2) + \dfrac{(x_j - \mu_{cj})^2}{\sigma_{cj}^2}\right]\)

The class with the larger score wins. On the two blobs the class means sit far apart, and the script's test half is perfect. Watch Naive Bayes, Clearly Explained.

0.3.3 Linear SVM

A linear SVM wants every point on the correct side of a line, and it wants the correct side to start at a margin of 1. The hinge is zero when \(y\,w^\top x \ge 1\) and grows linearly when the point is inside the margin or on the wrong side. Labels here are \(\{-1,+1\}\):

\(\ell = \dfrac{1}{N}\sum_i \max(0,\ 1 - y_i w^\top x_i) + \lambda \|w\|^2\)

Two hundred subgradient steps, with a column of ones for the bias, separate the blobs. Watch Support Vector Machines Part 1: Main Ideas.

0.3.4 k-means

k-means has no labels. It guesses \(k\) centers, assigns every point to the nearest center, then moves each center to the mean of its points. Repeat. On the two blobs with \(k = 2\), each true cloud ends up almost entirely in one cluster. Watch StatQuest: K-means clustering.

0.3.5 Bias, variance, and a train/test split

Bias is error from a model that is too stiff to follow the pattern. Variance is error from a model that follows the sample, including its accidents. A depth-2 tree on four points is the high-variance end. Ridge, which pulls weights toward zero, is a way to buy bias in exchange for less variance.

You cannot see either number on the rows you trained on. The script shuffles, keeps half for fitting kNN and naive Bayes, and scores accuracy on the other half:

\(\mathrm{accuracy} = \dfrac{1}{N}\sum_i \mathbf{1}[\hat y_i = y_i]\)

Watch Machine Learning Fundamentals: Bias and Variance.
