15.5 Advanced Concepts

Created Date: 2025-06-11

The GCN in the previous chapter runs on one small graph that fits in a single edge_index. These four topics are what changes when the graph does not fit, or when the training step should be compiled. The notes point at the PyG write-ups; the idea of each one is below.

Microsoft Research's Introduction to Graph Neural Networks is the lecture for the models these training tricks serve.

15.5.1 Advanced Mini-Batching

A batch of graphs is stored as one disconnected graph. Node features are concatenated, and edge_index is shifted so each graph keeps its own nodes. A batch vector records which graph a node belongs to, and a readout (mean or sum over that vector) produces one embedding per graph. Pairing nodes across graphs by accident is the bug this vector prevents. Advanced Mini-Batching covers the collate rules, including when a follow-batch index has to be built for a second tensor.

15.5.2 Memory-Efficient Aggregations

Materializing a message for every edge costs memory proportional to the edge count times the feature width. Sparse layouts and fused aggregations keep the neighbor sum in a kernel and never write that expanded tensor. Use them when the graph is large and the GCN from message_passing.py runs out of memory inside propagate. Memory-Efficient Aggregations is the menu of layouts. The mathematics of the sum does not change.

15.5.3 Hierarchical Neighborhood Sampling

A full neighborhood of a hub node can be most of the graph. Sampling draws a fixed number of neighbors at each hop, and a hierarchical scheme clusters nodes so the sample respects communities instead of picking uniformly. The GCN then runs on the sampled subgraph, with the same message as before. Hierarchical Neighborhood Sampling describes the clustering. You pay variance in the gradient for a bound on the subgraph size.

15.5.4 Compiled Graph Neural Networks

torch.compile can fuse the gather and the MLP inside a message-passing layer, but dynamic shapes — a different edge count every batch — are the usual reason the compile fails or silently falls back. Fix the sampled neighborhood size from the previous section and compilation has a static graph to work with. Compiled Graph Neural Networks lists which PyG layers compile cleanly. Compile after the eager GCN is correct, not before.
