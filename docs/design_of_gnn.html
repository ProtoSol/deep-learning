15.3.1 Creating Message Passing Networks

Generalizing the convolution operator to irregular domains is typically expressed as a neighborhood aggregation or message passing scheme. With \(\mathbf{x}^{(k-1)}_i \in \mathbb{R}^F\) denoting node features of node \(i\) in layer \((k-1)\) and \(\mathbf{e}_{j,i} \in \mathbb{R}^D\) denoting (optional) edge features from node \(j\) to node \(i\), message passing graph neural networks can be described as:

\[\mathbf{x}_i^{(k)} = \gamma^{(k)} \left( \mathbf{x}_i^{(k-1)}, \bigoplus_{j \in \mathcal{N}(i)} \, \phi^{(k)}\left(\mathbf{x}_i^{(k-1)}, \mathbf{x}_j^{(k-1)},\mathbf{e}_{j,i}\right) \right),\]

where \(\bigoplus\) denotes a differentiable, permutation invariant function, e.g., sum, mean or max, and \(\gamma\) and \(\phi\) denote differentiable functions such as MLPs (Multi Layer Perceptrons).

15.3.1.1 The "MessagePassing" Base Class

PyTorch Geometric's MessagePassing turns the formula above into five hooks. forward prepares node features and the edge index. message builds one vector per edge from the source node (and, if you ask, the target node and the edge attribute). The base class aggregates those messages with the aggr you chose in the constructor — "add", "mean", or "max" — which is the \(\bigoplus\) in the formula. update is the optional last map, \(\gamma\). You rarely call propagate's pieces yourself; propagate(edge_index, ...) runs message, aggregate, and update in order.

15.3.1.2 Implementing the GCN Layer

message_passing.py is a graph-convolution layer on that base class. The constructor sets aggr="add" and a bias-free linear map. forward follows the Kipf-Welling normalization:

  1. Add self-loops so a node is included in its own sum.

  2. Apply self.lin to the node matrix. Shape [N, in_channels] becomes [N, out_channels].

  3. Compute \(1/\sqrt{\deg(i)\deg(j)}\) from the edge index. A degree of zero would produce an infinity; those entries are set to zero.

  4. propagate calls message, which multiplies the neighbor features x_j by that coefficient.

  5. Add the bias.

The message function only sees the source node. The symmetric degree scaling is what makes this GCN rather than a plain sum of neighbors.

15.3.1.3 Implementing the Edge Convolution

Edge convolution uses the same base class and a different message. Instead of a scaled copy of \(x_j\), the message is a small network on the pair \((x_i, x_j - x_i)\), and the aggregator is usually "max" rather than "add". The subtraction is what makes the layer notice local shape: a neighbor that sits in the same place as the center contributes a zero offset. The repository's implementation stops at GCN. An edge-convolution layer is that class with aggr="max", a message that receives both x_i and x_j, and an MLP in place of the scalar norm.

15.3.1.4 Exercises

  1. Build a three-node path, run GCNConv(1, 1), and check that the two endpoints receive a different mix than the middle node.

  2. Change aggr from "add" to "mean" and watch the scale of the output drop as the degree grows.

  3. Write the edge-convolution message described above and confirm it returns zero offset on a pair of identical node vectors.
