9.6 DeepFaceLive

Created Date: 2025-06-03

DeepFaceLab, the previous page, trains a face swap offline: extract faces, train an autoencoder, merge the result back onto frames. DeepFaceLive is that trained swap running on a camera, one frame at a time. This repository does not ship the live application. The loop below is how the trained model gets used once DeepFaceLab has written it.

9.6.1 The live loop

Each frame goes through the same stages as the offline merge, with a budget of one frame interval. A detector finds the face. An aligner places the landmarks on the crop the model was trained with. The swap network, loaded from the DeepFaceLab checkpoint, writes a new face. A mask composites it onto the original frame so the background and the hairline stay put. Then the frame is shown or sent on.

The quality ceiling is the checkpoint. Live playback does not train. If the swap flickers, the usual causes are a detector that loses the face for a frame, an aligner whose crop does not match training, or a mask that is a frame late. Fix those before touching the network. The next chapter, Segment Anything, is a different segmentation model; it is not the mask inside this loop.
