8.3 Text-to-Speech

WhisperSpeech : An Open Source text-to-speech system built by inverting Whisper.

Created Date: 2025-08-14

WhisperSpeech is an open-source, text-to-speech (TTS) system created by “inverting” OpenAI Whisper. Our goal is to be for speech what Stable Diffusion is for images—powerful, hackable, and commercially safe.

Speech recognition in the previous section maps audio to text. This section runs the arrow the other way. WhisperSpeech trains a text-to-semantic model and a semantic-to-audio model so that a sentence becomes a waveform. The checkpoint names in the quick start are the pretrained pair; you do not train them to hear the first sample.

8.3.1 Quick Start

quick_start.py builds a pipeline from two checkpoints and writes a 24 kHz file:

pipe = Pipeline(
    t2s_ref="whisperspeech/whisperspeech:t2s-v1.95-small-8lang.model",
    s2a_ref="whisperspeech/whisperspeech:s2a-v1.95-medium-7lang.model",
)
audio_tensor = pipe.generate("This is the first demo of Whisper Speech, ...")
torchaudio.save("temp/temp.mp3", audio_tensor.cpu(), 24000)

t2s predicts semantic tokens from text, the same kind of token Whisper's encoder would have produced for real speech. s2a turns those tokens into samples. The languages in the checkpoint name are the ones the pair was trained to speak. A first run downloads the weights; later runs reuse them. Listen to temp/temp.mp3 before changing either name.

8.3.2 Finetuning

A new voice or a new language means more paired data: waveforms and their transcripts, at a sample rate the vocoder expects. Finetuning updates the text-to-semantic model, the semantic-to-audio model, or both. Keep the pretrained pair as the initialization. Training from scratch needs the scale of the original JUWELS run, which this folder does not repeat.

Hold out a few sentences and generate them after each checkpoint, the same pipe.generate call as the quick start with the new weights substituted. If the audio collapses to noise, the semantic tokens and the vocoder have drifted apart; finetune one stage at a time and leave the other frozen. The next page, speech separation, is a different problem — pulling two voices apart — and does not share these checkpoints.
