0.1 Linear Models

Created Date: 2026-10-09

A linear model predicts with a weighted sum. The four versions on this page differ in the penalty and in the loss. All four live in linear_models.py, which is NumPy and one assert per fit. Run python 00_ml/linear_models.py.

0.1.1 Linear regression

With a column of ones in \(X\), the weights that minimize the squared error have a closed form when \(X^\top X\) is invertible:

\(w = (X^\top X)^{-1} X^\top y\)

On the points \((0,1),\ (1,3),\ (2,5),\ (3,7)\) that equation returns \(w = (1, 2)\), the intercept and the slope of \(y = 1 + 2x\). The script checks that vector.

Josh Starmer's The Main Ideas of Fitting a Line to Data draws the squared gaps this formula is minimizing.

0.1.2 Ridge

Ridge adds a penalty on the size of \(w\). Large \(\lambda\) pulls every weight toward zero, which is what you want when columns of \(X\) are almost copies of each other and the plain inverse gets wild.

\(w = (X^\top X + \lambda I)^{-1} X^\top y\)

Same four points, \(\lambda = 10\). The script checks that this \(w\) is shorter than the unpenalized one. Watch Regularization Part 1: Ridge (L2) Regression.

0.1.3 Lasso

Lasso swaps the squared penalty for a sum of absolute values. The absolute value has a corner at zero, so a weight can land exactly on zero and the matching column drops out. There is no closed form. On a tiny problem, coordinate descent updates one weight at a time and shrinks it with the soft threshold:

\(S(z, \lambda) = \mathrm{sign}(z)\,\max(|z| - \lambda,\ 0)\)

The script builds \(y = 3 \times (\text{signal})\) plus a noise column, runs forty coordinate passes, and checks that the signal weight is larger than the noise weight. Watch Regularization Part 2: Lasso (L1) Regression.

0.1.4 Logistic regression

A sigmoid turns the weighted sum into a probability. The loss is binary cross-entropy, and a few gradient steps are enough to see it fall:

\(\sigma(z) = \dfrac{1}{1+e^{-z}}, \quad \ell = -\dfrac{1}{N}\sum_i \big[ y_i \log \sigma_i + (1-y_i)\log(1-\sigma_i) \big]\)

Two points at \(x = -1\) labeled 0, two at \(x = 1\) labeled 1. After eighty steps the loss is lower and the two sides of the line sit on opposite sides of \(0.5\). Watch StatQuest: Logistic Regression.
