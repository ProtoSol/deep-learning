7.2 Easy OCR

Ready-to-use OCR with 80+ supported languages and all popular writing scripts including: Latin, Chinese, Arabic, Devanagari, Cyrillic, etc.

Created Date: 2025-05-25

7.2.1 Simple Usage

Use Android's adb tool to take a screenshot of the phone and identify the content on the phone screen. The recognition step itself is three lines in demo_easy_ocr.py:

import easyocr

reader = easyocr.Reader(['ch_sim', 'en'])
result = reader.readtext('docs/res/00/cover.png')
print(result)

The first call downloads the detection and recognition weights for the languages you name. Each item in result is a box (four corner points), the string, and a confidence. ch_sim is simplified Chinese; add or drop language codes to change the recognizer. The detector finds text regions, the recognizer reads each crop. You do not pass a model class in.

couponing/command.py is the phone side of the same idea. It looks for an adb binary, lists device serials, and can send a key event. A screenshot grabbed with adb exec-out screencap -p is the image you then hand to readtext.

7.2.2 Train/use Your Own Model

The stock reader is enough when the glyphs are close to the training set. A private font, a receipt layout, or a domain vocabulary needs your own images and transcripts. EasyOCR's training path fine-tunes the recognition network: collect crops, write a label file of filename\ttext pairs, and train the recognizer while keeping the detector if the boxes are already reliable.

Point Reader at the new weights with the recog_network and model-storage arguments once training has written a checkpoint. Until that checkpoint exists, stay on the pretrained reader in the demo. Training is the slow part; inference stays the readtext call above.

7.2.3 Implementation Roadmap

The path through this folder is short on purpose.

  1. Run demo_easy_ocr.py on docs/res/00/cover.png and read the boxes it prints.

  2. Confirm adb with couponing/command.py if the image should come from a device rather than a file.

  3. Only after those two work, replace the recognizer with a fine-tune on your own crops.
