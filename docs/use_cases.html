15.4 Use-Cases & Applications

Created Date: 2025-07-21

The GCN in the previous chapter computes one vector per node. What you do with that vector is the task. Three tasks cover most applications, and they differ only in where the loss is attached.

15.4.1 Node prediction

Each node has a label, or a number. Citation networks, fraud flags on accounts, and traffic sensors are this shape. The loss is cross-entropy or squared error on the labeled nodes, and the unlabeled nodes still pass messages. The prediction at a node depends on its neighborhood because the layer summed that neighborhood.

15.4.2 Edge and graph prediction

Link prediction scores a pair of node vectors, often by a dot product, and the label is whether the edge exists. Recommendation and knowledge-graph completion are link prediction. Graph prediction pools every node vector — sum, mean, or a learned attention pool — into one vector and classifies the whole graph. Molecule property prediction is the usual example: atoms are nodes, bonds are edges, and the label belongs to the molecule.

The local code for the layer is still message_passing.py. This page does not add a dataset loader. Wire the GCN to whichever of the three losses matches the label you have, and read the next page when the graph no longer fits in one batch.
